# Проверки проекта

`npm run check` записывает STATIC_AUDIT.json в эту папку. Проверяются локальные ссылки, ресурсы и заголовки всех 36 страниц.

`npm test` выполняет 20 автоматических проверок калькулятора, анкеты, меню, локального обращения, поведения кнопки связи и уменьшения анимации. DOM-тесты не заменяют визуальную проверку на реальном телефоне.

GitHub Pages публикует ветку main после успешной сборки и проверок.
