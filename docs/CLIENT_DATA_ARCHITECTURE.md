# Клиентские данные: решение о запуске

Состояние: хранилище клиентов НЕ подключено. Владелец сообщил, что сервера в Казахстане пока нет. Сайт не собирает ИИН, не принимает документы и не сохраняет лиды. GitHub используется только для публичного кода и декоративных изображений. Даже private-репозиторий не подходит как база клиентов: нет требуемой локализации, удаления из истории и предметного контроля доступа.

## Что требуется для включения приёма

1. Определить юридическую сторону договора и оператора, его реквизиты, основания и цели обработки. Проверить профессиональный статус исполнителя отдельно.
2. Выбрать базу и файловый архив, физически находящиеся в Казахстане, включая резервные копии. Подтвердить размещение договором с провайдером. Не использовать зарубежную D1/R2/GitHub базу для ИИН.
3. Выделить отдельный HTTPS-домен для приёма с проверкой личности, подписанным/подтверждаемым согласием и версией текста. Отдельное необязательное согласие на маркетинг.
4. Минимизировать поля: первичное описание без ИИН; ИИН запрашивать только для обоснованной задачи. Без платёжных карт, SMS-кодов и доступа к банковским кабинетам.
5. Админ-доступ только с MFA, индивидуальные роли, короткие сессии и журнал доступа без содержимого документов/ИИН. Поисковые роботы и публичные ссылки к файлам не допускаются.
6. Шифрование транспорта и дисков, отдельное управление ключами и резервными копиями, проверка восстановления, антивирус/ограничение форматов загрузки, сроки хранения и удаления по задачам, обработка запросов субъекта и инцидентов.
7. Проверить все обработчики и трансграничные передачи. Согласие на передачу не отменяет требование локализации статьи 12 Закона РК о персональных данных.
8. Только после проверки включить серверный приём и обновить политику, согласие и договор. ИИН не передавать через URL, analytics, рекламный pixel или авто-prefill WhatsApp.

Это план внедрения, а не заявление о выполненной защите. Клиентские базы, документы, секреты, дампы и реальные логи не включать ни в публичный, ни в приватный репозиторий. Проверка доступных текущих функций: локальная память браузера; закрытый серверный приём отсутствует.
