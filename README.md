# QŪQYQ

Русско-казахский сайт об исполнительном производстве в Казахстане. Адаптирован для телефонов, содержит иллюстрации, анимации прокрутки, анкету и калькулятор.

## Разработка
Node.js 24+. `npm ci --ignore-scripts`, затем `npm run build`, `npm test`, `npm run check`. Исходники: frontend/, content-ru.json, content-kz.json. Результат: dist/.

## GitHub Pages
Репозиторий: timyname/quqyq-legal. В Settings → Pages выбрать GitHub Actions. Workflow публикует main после тестов. Путь /quqyq-legal/ учитывается отдельным скриптом; основной сайт сохраняет корневые пути. Ожидаемый адрес после успешной публикации: https://timyname.github.io/quqyq-legal/.

Текущий сайт: https://quqyq-legal.timyname.chatgpt.site.

Информационный проект; индексация отключена. Профессиональный статус и коммерческая готовность требуют подтверждения. Нет загрузки документов, платежей или внешнего трекинга. Данные форм обрабатываются локально. Иллюстрации и шрифты включены; лицензии сторонних компонентов находятся рядом с ними. 20 автоматических тестов; реальная проверка на Safari/iPhone ещё не выполнена.
